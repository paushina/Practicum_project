## О проекте

Учебный проект по анализу данных. Сеть фитнес-центров «Культурист-дата-сайентист» хочет снизить **отток клиентов** и строить стратегию взаимодействия с ними на основе данных.

> **Что считаем оттоком.** Клиент ушёл, если за последний месяц он **ни разу не посетил спортзал**. Бывает, что человек просто уехал в отпуск, но чаще такое отсутствие означает окончательный уход.

### Цели исследования

1. Спрогнозировать вероятность оттока каждого клиента на следующий месяц.
2. Выделить типичные портреты клиентов (кластеры) и описать их свойства.
3. Определить признаки, которые сильнее всего влияют на отток.
4. Сформулировать выводы и рекомендации: целевые группы и меры по удержанию.

## Исследуемые данные

Файл [`data/gym_churn.csv`](data/gym_churn.csv): **4000 клиентов**, **14 признаков**, пропусков и дубликатов нет. Доля оттока — **26.5%** (примерно каждый четвёртый клиент). Данные собраны за месяц до проверки факта оттока.

| Группа | Признаки |
|---|---|
| Целевой признак | `Churn` — факт оттока |
| Профиль клиента | `gender`, `Age`, `Near_Location` (живёт или работает рядом), `Phone` (оставил телефон), `Partner` (сотрудник компании-партнёра), `Promo_friends` (акция «Приведи друга») |
| Абонемент | `Contract_period` (длительность, мес.), `Month_to_end_contract` (мес. до окончания), `Lifetime` (мес. с первого обращения) |
| Поведение | `Group_visits`, `Avg_class_frequency_total`, `Avg_class_frequency_current_month` (посещений в неделю), `Avg_additional_charges_total` (траты на допуслуги) |

## Ход исследования

| № | Этап | Что сделано |
|:---:|---|---|
| 1 | **Загрузка данных** | чтение CSV, проверка типов |
| 2 | **EDA** | пропуски и дубликаты, `describe()`, средние по группам «ушли / остались» (`groupby`), распределения, матрица корреляций |
| 3 | **Модель оттока** | `train_test_split` (80/20, `stratify`), **Random Forest**, метрики accuracy / precision / recall на тесте, важность признаков |
| 4 | **Кластеризация** | стандартизация, матрица расстояний `linkage` (метод Уорда) и дендрограмма, **K-Means** на 5 кластерах, портреты кластеров и доля оттока в каждом |
| 5 | **Выводы** | ключевые закономерности и рекомендации по удержанию |

## Основные результаты

### Модель прогнозирования оттока

Метрики Random Forest на тестовой выборке (`random_state=0`):

| Accuracy | Precision | Recall |
|:---:|:---:|:---:|
| **0.922** | **0.875** | **0.825** |

- **Accuracy** не стоит читать отдельно: клиентов, которые остаются, 73.5%, поэтому «наивная» модель уже даёт высокий результат.
- **Precision**: из клиентов, которых модель назвала «уйдёт», реально уходят 87.5%. Чем выше, тем меньше трат на удержание тех, кто остался бы и так.
- **Recall** — ключевая метрика для удержания: модель находит 82.5% реально уходящих клиентов.

Сильнее всего на отток влияют `Lifetime`, частота посещений (за последний месяц и за всё время), возраст, траты на допуслуги и срок договора.

### Кластеры клиентов

K-Means выделил 5 групп с очень разным уровнем оттока:

| Кластер | Доля базы | Отток | Портрет |
|:---:|---:|:---:|---|
| **0** | 25.2% | 2.8% | «Долгосрочные партнёрские»: договор ~11 мес., 78% — сотрудники партнёров, 57% пришли по акции «Приведи друга» |
| **4** | 21.0% | 6.8% | «Самые активные»: ~2.85 посещения в неделю, несмотря на короткий договор |
| **1** | 9.6% | 26.8% | «Без телефона»: у клуба нет канала связи с клиентами |
| **2** | 12.6% | 44.4% | «Далёкие»: никто не живёт и не работает рядом с клубом |
| **3** | 31.6% | 51.4% | «Новички на коротком договоре»: `Lifetime` ~2.4 мес., частота посещений падает до ~1 в неделю |

### Выводы и рекомендации

- **Главный маркер риска — вовлечённость.** Падение частоты посещений и малый `Lifetime` — самые сильные сигналы скорого ухода.
- **Короткий договор опасен только в сочетании с низкой посещаемостью:** кластеры 3 и 4 похожи по длине договора, но отток у них 51.4% и 6.8%.
- **Партнёрство и «Приведи друга»** удерживают лишь часть клиентов (кластер 0) и не гарантируют результат сами по себе.

Что предлагается делать (подробнее — в разделе 5 ноутбука):

1. Сосредоточиться на кластере 3: онбординг для новичков (персональная тренировка, звонок куратора, челлендж), скидка при переходе на длинный абонемент.
2. Реагировать на падение посещаемости: автоматические сообщения и персональные предложения, использование модели как системы раннего оповещения.
3. Для «далёких» (кластер 2) — гибкие тарифы, онлайн-тренировки, партнёрские точки в других районах.
4. Собирать контакты клиентов (кластер 1): сам по себе телефон отток не снижает, но без него не работают остальные меры.
5. Не тратить бюджет удержания на кластеры 0 и 4, а использовать их как источник новых клиентов и кандидатов на длинные абонементы.

## Как запустить

```bash
# 1. Клонировать репозиторий
git clone https://github.com/paushina/gym-churn-analysis.git
cd gym-churn-analysis

# 2. Создать окружение (Python 3.9–3.11) и установить зависимости
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 3. Открыть ноутбук
jupyter notebook gym_churn_analysis.ipynb
```

> **О воспроизводимости.** Версия `scikit-learn` закреплена (`1.2.2`) не случайно: в более новых версиях K-Means при том же `random_state=0` может сойтись к другому разбиению, и номера и состав кластеров в описаниях перестанут совпадать с результатами. Метрики случайного леса от версии практически не зависят.
